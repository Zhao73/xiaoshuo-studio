# Xiaoshuo Studio Skill Index

## init

- `novel-init-wizard`: deep planning interview for a new book
- `webnovel-init`: lightweight project refresh

## reference

- `webnovel-import`: import excerpt or cleaned text
- `webnovel-import-folder`: import a whole local corpus
- `webnovel-scrape`: capture readable page text

## learning

- `webnovel-analyze-style`: turn text into a style card
- `webnovel-blend-style`: combine multiple style cards
- `novel-style-learn`: extract reusable technique

## planning

- `novel-load-context`: load canon and build brief
- `novel-plan-next`: plan the next chapter
- `webnovel-plan`: plan from project + style profile

## drafting

- `novel-draft-scene`: canon-aware drafting
- `webnovel-write`: style-driven drafting
- `webnovel-humanize`: humanize the draft
- `novel-anti-ai-pass`: explicit anti-AI pass

## review

- `novel-continuity-review`: continuity and canon check
- `webnovel-review`: structured draft review
- `webnovel-learn`: convert review into drills

## canon

- `novel-update-canon`: update project canon after an approved chapter
