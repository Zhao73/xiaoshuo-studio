# webnovel-plan

## Purpose

Turn project context and a chosen style profile into a concrete writing plan.

## Use It With

- Projects page
- Draft Queue
- Style Lab

Reference: `docs/local-codex-studio.md`

## Workflow

1. Confirm local Codex CLI health with `codex --version`.
2. Read the active project summary.
3. Pull in the selected style profile and at least one anti-AI focus item.
4. Produce a plan with:
   - goal
   - conflict
   - scene flow
   - hook target
   - anti-AI guardrails
5. Hand off cleanly to `webnovel-write`.

## Output

- A dashboard-ready plan summary and a Codex-ready execution brief.
