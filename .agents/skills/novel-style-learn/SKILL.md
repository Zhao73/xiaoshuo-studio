# novel-style-learn

## Purpose

Learn reusable technique from a private novel corpus.

Reference: `docs/local-codex-studio.md`

## Workflow

1. Import local novels or excerpts into the studio.
2. Analyze them into style cards and blend profiles.
3. Summarize what each source contributes:
   - pacing
   - dialogue density
   - scene break rhythm
   - hook style
4. Feed only the extracted technique into drafting.

## Guardrails

- Do not embed full novels inside a skill file.
- Read only the relevant corpus slices or derived style cards.
- Learn structure and craft patterns, not signature voice mimicry.
