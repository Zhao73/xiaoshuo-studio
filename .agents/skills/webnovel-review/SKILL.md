# webnovel-review

## Purpose

Produce a structured review that the dashboard can surface in Review Center.

## Use It With

- Review Center
- Draft Queue
- Learn Lab

Reference: `docs/local-codex-studio.md`

## Workflow

1. Confirm the latest draft and the active project context.
2. Review against four buckets:
   - story effectiveness
   - language naturalness
   - style-profile fit
   - AI-smell risk
3. Separate blocking issues from improvement notes.
4. Recommend the next action: revise, humanize again, or convert into a learning drill.

## Output

- Structured review notes that can feed both the dashboard and `webnovel-learn`.
