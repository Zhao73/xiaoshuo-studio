# webnovel-init

## Purpose

Initialize the project frame that the dashboard and later skills will use.

## Use It With

- Projects page
- Studio Home
- Codex CLI health in Settings

Reference: `docs/local-codex-studio.md`

## Workflow

1. Confirm the user is working inside the local `xiaoshuo` studio.
2. Check Codex CLI health with `codex --version`.
3. Gather or restate:
   - title
   - genre
   - premise
   - current project stage
4. Write or refresh the project frame in a way that the dashboard can surface.
5. End with the next recommended action: import references, analyze style, or draft a plan.

## Output

- A project summary that matches the dashboard's Projects view.
- A clear next step inside the studio workflow.
