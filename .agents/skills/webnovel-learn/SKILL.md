# webnovel-learn

## Purpose

Convert reference material and review findings into reusable training exercises.

## Use It With

- Learn Lab
- Review Center
- Reference Library

Reference: `docs/local-codex-studio.md`

## Workflow

1. Start from a reference, a style profile, a blended style profile, or a review report.
2. Extract the technique being studied:
   - pacing
   - dialogue pressure
   - scene exit hooks
   - anti-AI rewrite targets
3. Build a drill that asks the writer to practice the technique in their own scene.
4. Phrase feedback as technique transfer, not author imitation.
5. End with a short rubric the dashboard can display in Learn Lab.
6. If multiple references are involved, make clear what each source is teaching.

## Output

- A study note or practice drill aligned to the local studio workflow.
