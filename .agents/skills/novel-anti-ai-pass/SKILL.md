# novel-anti-ai-pass

## Purpose

Reduce AI smell without breaking canon continuity.

Use after `novel-continuity-review`.

## Workflow

1. Keep the approved facts fixed.
2. Revise for:
   - less explanation
   - fewer abstract emotion labels
   - less uniform sentence cadence
   - sharper scene-end pressure
3. Preserve the plot moves and canon facts.
4. If the rewrite changes facts, send it back through continuity review.

## Guardrails

- Never trade continuity for nicer prose.
- Do not overwrite the chapter's actual events while polishing tone.
- Avoid generic "naturalize this" instructions; use explicit anti-AI targets.
