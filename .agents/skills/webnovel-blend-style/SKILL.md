# webnovel-blend-style

## Purpose

Turn multiple reference-derived style cards into one mixed technique profile for writing.

## Use It With

- Blend Lab
- Style Lab
- Draft Queue

Reference: `docs/local-codex-studio.md`

## Workflow

1. Select at least two existing style cards.
2. State what each source contributes:
   - dialogue pressure
   - hook intensity
   - scene switching
   - anti-AI rewrite focus
3. Average the compatible metrics and merge anti-patterns.
4. Save the result as a mixed style profile.
5. Hand that profile to `webnovel-plan`, `webnovel-write`, or `webnovel-humanize`.

## Guardrails

- Blend techniques, not author voice.
- Make the contribution of each source explicit.

## Output

- A reusable blended style profile for current or future projects.
